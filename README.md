# magri.me

Personal website of **Matteo Magri** – Scientist in Structural Biology, Synchrotron Science, and Computational Biophysics at ESRF (European Synchrotron Radiation Facility), Grenoble, France.

Live website: [https://magri.me](https://magri.me)

## Features
- **Modern & Lightweight**: Zero dependencies, pure HTML5, modern CSS variables, and vanilla JavaScript.
- **Dark & Light Mode**: Automatic system preference detection with manual toggle and `localStorage` persistence.
- **Fast & Accessible**: Optimized for mobile, desktop, and all screen sizes.
- **GitHub Pages Ready**: Configured with custom domain `magri.me` via `CNAME`.

## Structure
- `index.html` - Main landing page markup
- `style.css` - Design system, themes (light/dark), layout, responsive styling
- `main.js` - Theme toggle, clipboard utilities, mobile navigation
- `favicon.svg` - Geometric SVG icon
- `CNAME` - Custom domain definition (`magri.me`)
